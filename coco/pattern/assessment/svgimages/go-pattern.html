PBAC Building Blocks

GO Pattern

Field-level access resolution for sensitive data. An identity requests a sensitive field; when a GroupID condition is supplied the engine returns a single PERMIT/DENY decision, and when it is omitted the engine instead returns the allowed action for every sensitive field.

Identity

A user who may belong to up to 50 unique centralized AD groups.

Asset

A single field requested from a fixed catalog of 40 predefined sensitive fields spanning PII, PHI, PCI, and PFI.

Action

The allowed action on a field is always one of two values: FULL or PARTIAL.

Condition

An optional GroupID input. When present, its location is compared against the Identity's location.

  • GroupID provided — the engine compares GroupID's location with the Identity's location and returns a single PERMIT or DENY decision.
  • GroupID omitted — the engine returns the full list of sensitive fields for the requested Asset, each mapped to the action (FULL or PARTIAL) the Identity is allowed, based on the Identity's location condition.
