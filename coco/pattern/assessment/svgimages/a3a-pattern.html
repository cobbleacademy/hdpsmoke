PBAC Building Blocks

A3A Pattern

Screen-and-action authorization for a valid identity. The engine checks whether the requested Action + Screen combination for the Identity exists in policy; a match returns PERMIT, and everything else defaults to DENY.

Identity

A valid Microsoft EntraID object (any authenticated user).

Asset

A requested Action (Update, View, or Modify) paired with a screen name.

Action

PERMIT if the Identity + Asset combination is defined in policy; DENY by default otherwise.

Condition

Policy membership — whether this exact Identity + Screen + Action combination has been configured as an allowed pair.

  • Combination matched — Identity, screen, and action together match a configured policy entry, so the engine returns PERMIT.
  • No match — any combination not explicitly defined in policy defaults to DENY.
